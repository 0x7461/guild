- **2026-08-15** — **rss-bot: `skip_curate` replaced by `favored` — personal blogs no longer bypass

- **2026-07-26** (later) — **Unified nagger's quota + reminders into one nag engine.** Refactored the initial two-path version (below) into a single `Nag` model: `{ID, Group, IntervalDays, Anchor, Render func(now)(string,bool)}`. Every signal is a periodic nag — the quota check is just the interval-1 special case with a live renderer and an empty anchor (= fire immediately when never fired); reminders are interval-91 with a static renderer and a required anchor. `main` builds `[]Nag{quotaNag, reminderNags...}`, evaluates `dueNag` for each against one unified `state.json` (id→last-fired, incl. `quota`), and fires the due ones as **one combined message** via `buildMessage` (groups blocks under `groupHeader`, ordered by `groupOrder` = reminders then quota). This kills the two-messages-on-a-due-day wart and collapses two dedup paths + two state files into one. `readState` migrates the old `last-sent`+`reminders-state.json` once if `state.json` is absent (then they're retired). Cadence differences are now just a field (`IntervalDays`), not separate wiring — adding a new signal type is one more `Nag` in the slice. Verified via dry-run: nothing-due (quota already sent today survives the migration), quota-only, and all-due combined. Design discussion with user drove the "everything is a periodic nag" reframe.
